# Quickstart: Simple Task Manager

## Prerequisites
- .NET 10 SDK
- Node.js LTS (Latest Stable)

## Backend Setup
1. Navigate to `backend/`
2. Run `dotnet restore`
3. Run `dotnet run`
   - API will be available at `http://localhost:5000` (or similar)

## Frontend Setup
1. Navigate to `frontend/`
2. Run `npm install`
3. Run `npm run dev`
   - UI will be available at `http://localhost:5173`

## Running Tests
- Backend: `dotnet test`
- Frontend: `npm test`
